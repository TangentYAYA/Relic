# 已知限制

1. 当前输入格式是 RAW/dd。提供的 `001Win10.E01` 至 `E15` 是 Guymager EWF
   分卷，需要后续 EWF 解码或预转换流程；Relic 不应直接把 E01 分片当完整镜像。
2. TSK CLI 通过 `RELIC_TSK_BIN` 指向外部安装目录，PyInstaller 不会把 TSK
   可执行文件嵌入程序。
3. 报告仅为 Markdown，不提供 HTML/PDF 渲染。
4. 文件类型识别仅覆盖已实现签名；扩展名异常不是恶意行为结论。
5. 关键词搜索第一阶段只处理无 NUL 且可 UTF-8 解码的纯文本。
6. 审计哈希链可以检测部分篡改、乱序、缺失和尾部变化，但不能阻止拥有文件系统
   权限的人重写整个日志。
7. 软件级只读访问不等同于硬件写保护器。
8. 性能数据来自小型构造 fixture，不代表大型真实镜像；完整进程 RSS 尚未纳入
   自动化性能采样。
9. 磁盘空间不足依赖 Windows 文件系统返回错误；测试没有通过耗尽真实磁盘来模拟。
