# Relic 用户手册

## 1. 启动前配置

设置 TSK CLI 和案件数据目录：

```powershell
$env:RELIC_TSK_BIN = "D:\sleuthkit\sleuthkit\bin"
$env:RELIC_CASE_ROOT = "D:\RelicData"
.\.venv\Scripts\python.exe main.py
```

案件目录应与原始证据目录分离。Relic 不复制或修改原始镜像。

## 2. 案件和证据

在“案件管理”创建或打开案件，在“证据管理”选择 RAW/dd 镜像。系统登记绝对
路径后调用 TSK 识别分区；选定分区后读取文件系统信息。SHA-256 基线和结束复核
均为后台流式操作。

当前不支持 E01/EWF、AFF 等容器。不要把分卷 E01 的单个分片作为完整 RAW 镜像导入。

## 3. 文件浏览和分析

“文件系统分析”通过 TSK 展示目录、文件、inode、大小和时间；详情使用 `istat`。
导出使用 `icat`，目标位于当前案件的 `exports` 目录并记录 SHA-256。

“内容分析中心”支持内容签名识别、扩展名异常、纯文本关键词、支持范围内的
图片 EXIF、缩略图以及标记和备注。未知格式会明确显示为未知，不推断恶意行为。

## 4. 审计、完整性和报告

关键操作写入案件根目录的 `audit.jsonl` 哈希链。完整性中心可执行结束哈希复核、
检查点和质量检查。报告中心只生成 `reports/*.md`，可查看 Markdown 预览和源码，
不会生成 HTML，也不会把缺失结果写成成功。

审计链是检测机制，不是不可修改存储；请用外部权限、只读介质或独立存储保护日志。
